# Health-Hub Africa Website

A responsive static website for Health-Hub Africa, built with semantic HTML, CSS and lightweight JavaScript.

## Preview locally

From this folder, run:

```powershell
py -m http.server 4173 --bind 127.0.0.1
```

Then open `http://127.0.0.1:4173/`.

## Pages

- `index.html` — homepage
- `about.html` — organisation story, mission and founder
- `services.html` — seven integrated healthcare services
- `people.html` — individuals and organisations served
- `contact.html` — contact channels and Lagos locations

## Before production

Confirm all medical claims, telephone numbers, location details and operating-location counts with Health-Hub Africa. Replace or expand photography if final commissioned brand imagery becomes available.
